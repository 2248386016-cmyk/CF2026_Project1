# 周频 vs 月频对照实验证据

## 数据与假设

- 两组共用数据库、动态沪深主板资产池和复权口径。
- 样本区间：2020-01-01 至 2025-12-31。
- 两组均为前20名等权，买入费率0.0300%，卖出费率0.1300%。
- 唯一改变：每周首个交易日 vs 每月首个交易日调仓。
- 原始数据快照文件数：9503；快照清单SHA-256：2f8f8b212baf1f933ab9ea8442b1df4815c68590f5cbfb232f2f0411dfea4c36。
- 未建模：冲击成本、滑点、整手约束、行业/市值中性化；退市无法卖出按零回收率核销。

## 三因子与回测

- 因子：20日低波动、5日反转、20日Amihud非流动性。
- 周频：年化收益 20.40%，Sharpe 0.897，最大回撤 40.21%，成本 691,116元。
- 月频：年化收益 28.34%，Sharpe 1.214，最大回撤 30.04%，成本 233,288元。

## 对照与解释

- 换手变化：517.51 → 130.55。
- 交易次数：11304 → 2707。
- 平均实际持仓：36.17 → 31.47。
- 最大单股权重：7.48% → 10.35%。
- 只有调仓频率变化，因此收益、风险和成本差异可主要归因于信号更新速度与换手的变化。
